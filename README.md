# Standby.y สำหรับ Mac

ที่เก็บไฟล์ติดตั้งและอัปเดตของแอพ Standby.y (ไม่มีโค้ดของแอพใน repo นี้)

## ติดตั้งครั้งแรก

ใช้ได้กับ Mac ชิป Apple (M1 ขึ้นไป) และ macOS 14 ขึ้นไป

1. เปิด [เวอร์ชันล่าสุด](https://github.com/ChocoHusky17/standbyy-releases/releases/latest) แล้วดาวน์โหลดไฟล์ `Standby.y-….zip`
2. ดับเบิลคลิกเพื่อแตกไฟล์ แล้วลาก `Standby.y` ไปไว้ในโฟลเดอร์ Applications
3. ครั้งแรกให้คลิกขวาที่แอพ แล้วเลือก "เปิด" และกด "เปิด" อีกครั้ง
   (แอพยังไม่ได้ลงทะเบียนกับ Apple จึงต้องอนุญาตเองครั้งแรก ถ้าไม่มีปุ่มเปิด ให้ไปที่
   System Settings › Privacy & Security แล้วกด "Open Anyway")
4. เข้าสู่ระบบด้วยบัญชีที่เจ้าของร้านสร้างให้

## อัปเดต

แอพตรวจหาเวอร์ชันใหม่เองวันละครั้ง และถามก่อนติดตั้ง หรือกดเมนู Standby.y › ตรวจหาอัปเดต…
ไฟล์อัปเดตทุกไฟล์ถูกเซ็นด้วยกุญแจของร้าน แอพจะไม่ติดตั้งไฟล์ที่ลายเซ็นไม่ตรง

## ข้อควรระวังสำหรับทีมทดสอบ

แอพเชื่อมกับระบบจริงของร้าน การส่งข้อความจะถึงลูกค้าจริง ให้ทดลองส่งเฉพาะในแชท LINE ของตัวเอง
